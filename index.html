Boot the Local Control Plane in 30 Seconds ​

bash
# Install via macOS Homebrew Tap (background daemon) or uv pip (Python 3.12+ SDK & CLI)
$ brew install dphilabs/fiber/fiber
# OR: uv pip install git+https://github.com/dphilabs/fiber.git

$ fiber init          # Provision workspace (~/.anchor) & local node keys
$ fiber connect all   # Non-invasively harvest IDE MCP configs into ~/.anchor/mcp.json
$ fiber console       # Launch Gateway daemon (:8356) & Console Studio UI (:8357)
